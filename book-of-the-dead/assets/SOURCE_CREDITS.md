# Source and asset record

## Facsimile images and cover

The supplied project identifies the source of `scans/ani-01.webp` through `scans/ani-37.webp` as E. A. Wallis Budge, *The Book of the Dead: Facsimile of the Papyrus of Ani*, second edition, London, 1894, digitized by Heidelberg University Library. These files are scans of the printed facsimile, not new photographs of the original papyrus. The original project records report Public Domain Mark 1.0; verification against the originating record remains an explicit release gate, not a newly certified legal conclusion in this packaging milestone.

Source collection: https://digi.ub.uni-heidelberg.de/diglit/budge1894bd1

The `cover.webp` and `cover.jpg` assets are 1600 × 900 web derivatives of the bundled sheet 3 image, rendered at a centered 16:9 crop and encoded for web use. No historical figure, inscription or feature was generated, replaced or retouched. They are not film frames or screenshots of concept art.

The facsimile tiles and overview are preserved byte-for-byte from the supplied v2.4 archive. The main tile set uses a normalized 1,200-pixel painted-band height, inherited from the original image preparation. The larger source scans are not included here.

## Historical text

The inherited corpus identifies the historical English translation and vignette descriptions as E. A. Wallis Budge, *The Book of the Dead: The Papyrus of Ani* (1895), using the Internet Sacred Text Archive transcription. The historical text is retained as a historical source, not represented as a modern critical translation.

Transcription entry: https://sacred-texts.com/egy/ebod/ebod13.htm

No new modern translation, transliteration or source correction is claimed in this version. The guide, spell notes, region associations and thematic map groupings remain editorial material requiring review.

## Application and visualization

The original static viewer and annotation dataset are continued from the supplied project. The current native WebGL renderer is original project code; its cylinder, rings, positions, blank panels and optional route are modern interface choices. The movie reference supplied by Scott informs only the visual direction, not the religious content or geographic claims.

No movie stills, film footage, copied film glyphs, generative concept-art textures, third-party JavaScript packages, third-party font files or remote services are distributed in this folder. The favicon uses a system-rendered letter; no font file is bundled.
